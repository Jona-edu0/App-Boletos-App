# Ticket Star

Aplicación web de venta de boletos para funciones de circo, desarrollada con React y Vite.

## Aplicación

La app está publicada en GitHub Pages:

**https://jona-edu0.github.io/App-Boletos-App/**

## Desarrollo local

```bash
cd boletos-app
npm ci
npm run dev
```

## Publicación

El workflow de GitHub Actions compila y publica `boletos-app/` en GitHub Pages al hacer push a `main`, e intenta habilitar Pages automáticamente. Si la política del repositorio u organización lo impide, habilítalo en **Settings → Pages → Build and deployment → Source → GitHub Actions**.

Más información sobre el proyecto, sus funcionalidades y tecnologías en [boletos-app/README.md](./boletos-app/README.md).
